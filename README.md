# Multi Pendulum Executive Toy

Two configurable double or triple pendulums on one frame. Compare identical
starts with a small angle difference. Drag or swipe to orbit the view.

Static release: HTML, CSS, JavaScript, compiled WebAssembly and loader.
No build is required. Serve this branch from its repository root.

For GitHub Pages, choose `mpend-exec-toy` and `/ (root)`.
Requires WebGL and WebAssembly. Open in Safari on iPhone.

Release: mpend-exec-r1 (2026-10-12).
